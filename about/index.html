About

我叫 Zuwei Wang。

这个博客是我用来记录 计算机、音乐、以及思考本身 的地方。

我并不把它当作教程站，也不把它当作日记。
更准确地说，它更像是一份 持续更新的思考笔记：
有些想法来自课堂，有些来自项目，有些来自音乐，有些来自生活中那些说不清、但反复出现的瞬间。

我在写什么

目前，这个博客主要包含几个方向：

  • CS / 技术
    不只是“怎么做”，而是为什么这样设计、这样理解更合理。

  • 音乐与感知
    尤其关注节奏、时间、记忆与身体反应之间的关系。
    有时会从嘻哈、电子音乐出发，用更偏科学或工程的视角分析“为什么会被击中”。

  • Thinking
    一些关于学习、系统、认知、决策的非即时结论。

  • Life（少量）
    只记录那些对理解自己有帮助的部分。

为什么要写下来

很多体验如果不写下来，很快就会被情绪覆盖、被时间模糊。
而一旦用语言和结构固定下来，它们就会变成可以反复审视的对象。

我写作的目的不是输出观点，
而是逼自己把模糊的感觉，压缩成清晰的结构。

如果这些结构恰好也能帮到别人，那是额外的收获。

如何阅读这个博客

如果你是第一次来，可以从 Categories 或 Tags 开始浏览。
每一篇文章都是相对独立的，不需要按时间顺序阅读。

这个博客不追求更新频率，也不追求结论的完整性。
它更像一条正在铺设的轨道，而不是已经画好的地图。

联系我

如果你对某篇文章有想法，或只是想交流观点，
可以通过 GitHub 找到我。

这个博客本身，就是我目前最准确的自我介绍。
